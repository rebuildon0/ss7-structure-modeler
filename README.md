# SS7 Structure Modeler

SS7 の「CSV 出力（全項目）」を Rhino 用 3D モデルに変換するブラウザ版です。

## 使い方

1. SS7 で「CSV 出力（全項目）」を保存します。
2. 公開ページで CSV を選び、「3D モデルを作成」を押します。
3. 3DM をダウンロードして Rhino で開きます。DXF、OBJ、変換レポートも個別にダウンロードできます。

CSV と生成ファイルはブラウザ内のメモリで処理し、サイトのサーバーへ送信しません。元 CSV は変更されません。100 MB まで選択できますが、大きいファイルの処理には相応の端末メモリが必要です。初回は変換エンジンの読み込みに時間がかかります。

変換エンジンには [Pyodide](https://pyodide.org/) と [rhino3dm.js](https://github.com/mcneel/rhino3dm) を使用します。これらの実行ファイルはバージョンを固定して CDN から取得します。CDN に CSV の中身は送信しません。

このツールは形状モデルを生成します。変換レポートの未展開項目や仮断面を確認し、業務に使う前に Rhino 上の形状を原データと照合してください。
